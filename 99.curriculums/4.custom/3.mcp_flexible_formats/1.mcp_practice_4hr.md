# 1. MCP 실전 4시간 — 예제 중심

모듈 ID(M0, M16 등)의 정확한 폴더/분량은 [`0.base.md`](0.base.md)의 모듈 카탈로그 참고.

**대상** MCP 처음 개발자, 그중에서도 **agent가 여러 MCP 도구를 라우팅·순차 실행하는 것**과
**HITL**을 반드시 체감시키고 싶은 경우
**구성** `M0 → M0.5a+b(llm-math 복습) → M1(stdio)+M3(transport) → M19+M20(mcp-math 로컬/원격) → M16(라우팅 3단)+M17(실전 분기) → M18(HITL)`

**전체 스토리라인 — 같은 "계산기"를 처음부터 끝까지 끌고 간다**:
1. **호출**만 해본다(빌트인 llm-math) → 2. **직접 만들어**본다(`@tool`, 근데 LangChain 프로세스 안에 갇힘)
→ 3. MCP **프로토콜**(초기화→도구목록→호출)과 **전송**(stdio/HTTP) 개념 →
4. 그 계산기를 **MCP 서버로 다시 만들어** 로컬(stdio)로, 그다음 원격(HTTP)으로 연동(**코드는 `mcp.run()` 한 줄만 다름**) →
5. 계산기 하나가 아니라 **여러 MCP 서버를 라우팅** — 도구 이름을 코드에 박아 부르던 것에서
→ **키워드 규칙**으로 → **LLM(GPT)이 스스로 선택**하는 것까지 3단계로 고도화하고, **실전에서 순차·분기**시키기 →
6. 마지막으로 **안전장치(HITL)**. "같은 도구가 프로세스 안 → MCP 로컬 → MCP 원격 → 여러 개(규칙→LLM 라우팅)"로
커지는 걸 몸으로 따라가게 만드는 게 이 포맷의 핵심이다.

**4대 섹션**. "LLM과 MCP가 어떻게 상호작용하는지"는 3번(라우팅·순차·분기) 데모 안에서
**"LLM이 뭘 보고 어떤 도구를 고르고, 그게 어떻게 `call_tool`로 이어지는지"** 를 직접 관찰하며 확인한다 —
별도 블록 없이 그 데모 자체가 실물이다.

| 섹션 | 시간대 | 포함 블록 |
|---|---|---|
| **1. MCP 프로토콜 개요**(agent·tool calling + MCP stdio) | 0:00–1:15 (75m) | 오리엔테이션 → llm-math 호출/직접제작 복습 → MCP stdio 첫 왕복 + debug_proxy |
| **2. MCP 프로토콜을 통한 연결과 동작실행** | 1:15–2:10 (55m, 휴식 포함) | transport 비교 → mcp-math 로컬(stdio) 연동 → mcp-math 원격(HTTP) 연동 |
| **3. MCP tool 연결·Routing·순차실행·조건분기** (LLM↔MCP 상호작용 포함) | 2:10–3:30 (80m, 휴식 포함) | 여러 서버 라우팅 3단(단독→규칙→GPT) → 실전 순차·분기(멀티 컨시어지) — *"지금 LLM이 왜 이 도구를 골랐는지" 매 호출마다 관찰* |
| **4. Human-in-the-loop와 통합** | 3:30–4:00 (30m) | HITL 원리 → 라이브 데모(압축) → 마무리 |

> 마무리는 별도 시간 없이 HITL 데모 말미에 5번 보너스(아래)를 한 줄로 언급하고 끝낸다 — 4시간이 꽉 차 있다.

> 이 4시간 동안 LLM을 실제로 부르는 코드는 대부분 **LangChain `create_agent`** 를 쓴다. 프로토콜만 다루는
> M1·debug_proxy·M3·M19는 LLM 자체가 없는 **raw MCP SDK** 코드고, **M16의 3.smart_client_manual.py·
> 4.smart_client_gpt.py 두 개만 예외로 raw OpenAI SDK** 다 — "규칙 기반 → LLM 라우팅"으로 넘어가는
> 순간 자체가 이 블록의 핵심이라, LLM이 도구 스키마만 보고 뭘 부를지 스스로 정하는 raw 메커니즘을
> 한 겹 벗겨서 보여주려는 의도적 선택이다(자세한 이유는 [`exercise/README.md`](exercise/README.md) 참고).

넣으려면 다른 데서 15~20분을 덜어와야 한다 — 가장 만만한 곳은 HITL 라이브 데모(3:40–4:00, 이미
압축된 20분이라 더 줄이긴 어려움)나 M17 실전 순차·분기(30분 → 20분으로) 쪽.
