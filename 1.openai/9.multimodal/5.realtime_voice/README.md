# 5.realtime_voice — 실시간 음성 (오디오 ↔ 오디오)

오디오 입력과 출력을 함께 다루는 두 가지 접근을 모읍니다. 구현 방식이 서로 다릅니다.

| 디렉토리 | 방식 | 내용 |
|----------|------|------|
| [`1.webrtc_app/`](1.webrtc_app/) | STT + GPT 요약 (다자간) | 여러 사용자의 마이크 음성을 실시간 자막으로 방송해 **하나의 회의록**으로 누적, 버튼으로 GPT 요약. Flask + Flask-SocketIO |
| [`2.audio_chat/`](2.audio_chat/) | gpt-4o-audio (단일 모델) | **오디오 입력 → 오디오 출력을 모델 하나**가 처리(STT+TTS 2단계가 아님). 1:1 음성 대화, 연속 대화(맥락 유지) 포함 |

`1.webrtc_app`은 **다자간 회의록**(누가 어떤 말을 했는지 누적·요약)이 목적이고,
`2.audio_chat`은 **1:1 음성 대화**에서 gpt-4o-audio 하나로 듣고 이해하고 답하는 것이 목적입니다.
STT만 필요하면 [`../3.stt/`](../3.stt/), TTS만 필요하면 [`../4.tts/`](../4.tts/)를 참고하세요.
