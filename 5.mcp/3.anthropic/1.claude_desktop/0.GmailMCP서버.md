# Gmail MCP 서버 설정 가이드

> 📝 **2026-08 갱신**: 원래 이 문서가 쓰던 `@modelcontextprotocol/server-google-gmail`,
> `@modelcontextprotocol/server-imap`은 **실재하지 않는 패키지**였다(npm 레지스트리에서 404 확인).
> 검색·검증을 거쳐 실제로 존재하고 유지보수 중인 패키지(`imap-mcp-server`, 2주 전 배포된
> v2.0.0)로 내용을 전부 교체했다. OAuth(Google API) 방식은 검증된 오픈소스 MCP 패키지를 찾지
> 못해 참고용으로만 남겨뒀다 — 아래 "방법 2" 참고.

## 개요
MCP (Model Context Protocol)를 사용하여 Gmail을 Claude Desktop과 연동하는 가이드입니다.
**IMAP + 앱 비밀번호** 방식(방법 1)이 지금 바로 검증 가능한 유일한 경로입니다.

## 사전 요구사항
- Claude Desktop 앱 설치
- Node.js 18+ (npx 사용)
- Gmail 계정 + 2단계 인증 활성화(앱 비밀번호 발급에 필요)

## 방법 1: IMAP 사용 (검증됨, 권장)

패키지: [`imap-mcp-server`](https://github.com/nikolausm/imap-mcp-server) — npm에 실제 배포 중
(`npm view imap-mcp-server`로 직접 확인: v2.0.0, MIT 라이선스, 12개 버전 이력).

### 1단계: Gmail 앱 비밀번호 생성

1. [Google 계정 설정](https://myaccount.google.com) → "보안" → "2단계 인증" 활성화
2. "보안" → "앱 비밀번호" → 앱: "메일", 기기: "기타(맞춤 이름)" → "Claude Desktop" 입력
3. **생성된 16자리 비밀번호 복사**(한 번만 표시됨!) — Gmail 계정 비밀번호가 아니라 이 앱 비밀번호를 쓴다

### 2단계: Claude Desktop 설정

설정 파일 위치:
```bash
# macOS
~/Library/Application Support/Claude/claude_desktop_config.json
# Windows
%APPDATA%\Claude\claude_desktop_config.json
# Linux
~/.config/Claude/claude_desktop_config.json
```

```json
{
  "mcpServers": {
    "imap": {
      "command": "npx",
      "args": ["-y", "imap-mcp-server"],
      "env": {}
    }
  }
}
```
`env`가 비어 있는 게 정상이다 — 계정 자체는 아래 3단계의 설정 마법사로 등록한다(호스트/포트/TLS
설정은 환경변수로 못 넘긴다 — `accounts.json`에 저장되는 구조라서다).

### 3단계: 계정 등록(설정 마법사)

```bash
npx -p imap-mcp-server imap-setup
```
로컬 웹서버가 뜨고 브라우저가 자동으로 열린다. 마법사에서:
- 이름: `Gmail`(자유), Provider 프리셋에서 **Gmail 선택** → 호스트(`imap.gmail.com`)/포트(`993`)
  자동 입력
- Username: Gmail 주소, Password: **1단계에서 만든 16자리 앱 비밀번호**

저장하면 `~/.imap-mcp/accounts.json`에 **AES-256으로 암호화**되어 저장된다. Claude Desktop을
재시작하면 도구 패널에 `imap` 서버가 나타난다.

### 4단계: 확인
Claude에서 "Gmail 계정 목록 보여줘" 또는 "최근 이메일 5개 보여줘"라고 물어보면 동작을 확인할 수 있다.

### 주요 도구 (일부)
| 분류 | 도구 | 기능 |
|---|---|---|
| 계정 | `imap_add_account`, `imap_list_accounts`, `imap_test_account` | 계정 추가/목록/연결 테스트 |
| 읽기 | `imap_search_emails`, `imap_get_latest_emails`, `imap_get_email` | 검색·최근 메일·본문 조회 |
| 상태 변경 | `imap_mark_as_read`, `imap_flag_email`, `imap_move_email` | 읽음 처리·별표·폴더 이동 |
| 발송 | `imap_send_email`, `imap_reply_to_email`, `imap_forward_email` | 새 메일·답장·전달 |
| 폴더 | `imap_list_folders`, `imap_get_unread_count` | 폴더 목록·안읽음 수 |

(전체 목록은 저장소 README 참고 — 위 링크)

## 방법 2: Google API(OAuth) 사용 — 참고용, 검증된 패키지 없음

`credentials.json` + OAuth 동의 화면을 거치는 방식은 Gmail API를 정식으로 쓰는 더 강력한 방법이지만,
**2026-08 기준 이 흐름을 그대로 구현한 유지보수 중인 오픈소스 MCP 서버를 찾지 못했다**(검색된
후보들은 실험적이거나 npm에 배포되지 않았음). 아래는 "만약 그런 서버를 직접 만들거나 찾는다면"
공통으로 필요한 Google 쪽 준비 절차다 — 그 자체는 유효하다:

1. [Google Cloud Console](https://console.cloud.google.com) → 새 프로젝트 생성
2. "API 및 서비스" → "라이브러리" → **Gmail API** 사용 설정
3. "OAuth 동의 화면" 구성(사용자 유형: 외부/개인용)
4. "범위 추가" → `gmail.readonly` / `gmail.modify` 중 필요한 것
5. "사용자 인증 정보" → OAuth 클라이언트 ID(데스크톱 앱) 생성 → **credentials.json 다운로드**

실제로 MCP 서버에 연결하려면 이 `credentials.json`을 받아주는 실제 서버 구현이 필요하다 — 새
패키지를 검색할 땐 반드시 `npm view <패키지명>`으로 실재 여부와 최근 배포일을 먼저 확인할 것
(이 문서가 원래 겪은 문제가 정확히 이거였다).

## 고급 설정

### 여러 Gmail 계정 (개인 + 회사 등)
`imap-mcp-server`는 **서버 하나로 여러 계정을 동시에** 관리한다(별도 `mcpServers` 항목을
안 늘려도 된다) — `imap-setup` 마법사를 다시 실행해 계정을 추가로 등록하거나, Claude 안에서
직접 `imap_add_account` 도구를 호출해도 된다. 도구 호출 시 `accountName`으로 어느 계정인지
지정하고(계정이 하나뿐이면 생략 가능), 자격증명만 환경변수로 덮어쓰고 싶으면:
```json
{
  "mcpServers": {
    "imap": {
      "command": "npx",
      "args": ["-y", "imap-mcp-server"],
      "env": {
        "IMAP_MCP_ACCOUNT_WORK_GMAIL_IMAP_USERNAME": "work@company.com",
        "IMAP_MCP_ACCOUNT_WORK_GMAIL_IMAP_PASSWORD": "앱비밀번호16자리"
      }
    }
  }
}
```
(계정 이름 `Work Gmail`을 대문자+언더스코어로 정규화한 `WORK_GMAIL`이 변수명에 들어간다.
호스트/포트는 여전히 환경변수로 못 바꾼다 — `accounts.json`/마법사 몫이다.)

### 다른 서비스와 함께 사용
공식 filesystem 서버(`@modelcontextprotocol/server-filesystem`, 실재 확인됨)와는 그냥
`mcpServers`에 나란히 추가하면 된다:
```json
{
  "mcpServers": {
    "imap": {
      "command": "npx",
      "args": ["-y", "imap-mcp-server"],
      "env": {}
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/yourname/Documents"]
    }
  }
}
```

## 사용 예시

Claude Desktop에서 다음과 같이 자연어로 요청하면 된다(모델이 위 도구 중 알맞은 걸 스스로 고른다):

```
최근 받은 이메일 10개를 보여줘
오늘 받은 이메일 중 중요한 것들을 요약해줘
"프로젝트"라는 키워드가 포함된 이메일을 찾아줘
읽지 않은 이메일에 별표 표시해줘
```

## 문제해결

**"계정을 찾을 수 없음" / 도구 호출 실패**
- `imap-setup` 마법사로 계정을 실제로 등록했는지 확인 (`~/.imap-mcp/accounts.json` 존재 여부)
- `imap_test_account` 도구로 연결 테스트

**"인증 실패"(Gmail)**
- Gmail 계정 비밀번호가 아니라 **앱 비밀번호**(16자리)를 썼는지 확인
- 2단계 인증이 켜져 있어야 앱 비밀번호를 만들 수 있다

**Claude Desktop에 서버가 안 보임**
- `claude_desktop_config.json` JSON 문법 오류 확인, Claude Desktop 완전 재시작

### 로그 확인
```bash
# macOS
tail -f ~/Library/Logs/Claude/claude_desktop.log
# Windows
type "%APPDATA%\Claude\Logs\claude_desktop.log"
```

## 보안 고려사항
1. `accounts.json`은 AES-256으로 암호화되어 `~/.imap-mcp/`에 저장된다 — 그래도 이 디렉터리
   자체의 접근 권한은 사용자 계정으로 제한할 것.
2. **최소 권한**: 이 서버는 읽기/쓰기/발송 도구를 전부 노출한다 — 실수로 메일을 삭제·발송하는
   게 걱정되면 특정 도구만 허용하는 `IMAP_MCP_ENABLED_TOOLS` 환경변수로 범위를 좁힐 것.
3. **민감한 이메일**: 개인정보나 기밀 정보가 Claude에 노출됨을 인지할 것.
