4b · 자동승인 + 고위험 인자는 항상 재확인

조회는 자동 통과({{ safe|join(', ') }}) · 나머지는 승인 대상 · [항상 승인] 을 누르면 그 기능은 다음부터 안 묻는다 — 단 grant_access 의 group 이 고위험(prod-db·payroll)이면 예외 없이 매번 재확인

⚡ 자동승인 목록

아직 없음 — 전부 물어본다

여기 올라간 기능은 승인 없이 실행된다. 단, 고위험 인자는 예외.

🗄 DB 현황

MCP 를 거치지 않고 DB 를 직접 읽는다 — 에이전트가 정말 바꿨는지 확인용.

예제 프롬프트
  1. 오지훈 온보딩 해줘. 계정 jihoon, email·vpn 권한
    • create_account 승인 카드에서 [항상 승인] 을 눌러 보기
    • 이어지는 grant_access 카드에서도 [항상 승인] (email 만 있을 수도, vpn 까지 같이 있을 수도 있다) — grant_access 도 목록에 오른다
  2. 박민수한테 vpn 권한 줘
    • vpn 은 고위험이 아니라서 안 묻는다 (a 와 동일하게 동작)
    • 작업 로그에 ⚡ 자동승인 으로 남는다
  3. 박민수한테 prod-db 권한 줘
    • grant_access 는 자동승인 상태인데도 승인 카드가 뜬다 — prod-db 가 고위험이라서
    • 이 카드에는 [항상 승인] 버튼이 없다 — "이번만 봐줘"는 있어도 "고위험은 앞으로도 자동으로"는 이 단계에서 아예 선택지에서 뺐다
    • a 였다면 이 요청은 그냥 아무 표시 없이 나갔다 — 비교해서 확인해 볼 것
  4. 박민수한테 payroll 권한 줘
    • payroll 도 고위험이라 마찬가지로 매번 재확인 — 어떤 사번·어떤 그룹이든 예외 없음
